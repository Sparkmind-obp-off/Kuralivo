# KURALIVO — UI Screen Specifications

## 1. Overview
**Purpose:** Resume work quickly.  
**Content:** active projects, drafts needing review, recent publications, next experiment.  
**Empty state:** one clear action to create a project; no fake metrics.

## 2. Project brief
**Fields:** project name, product/context, audience, audience problem, channel, language, objective, format, CTA, constraints.  
**Behavior:** allow saving incomplete work; explain missing inputs before generation.

## 3. Evidence pack
**Fields:** source URL/title, date checked, claim, limitation, permission note, confidence.  
**Behavior:** a URL alone does not make a claim verified; show conflicting sources.

## 4. Creative planner
**Content:** angle, hook, audience problem, supporting evidence, format, CTA, risk, learning hypothesis.  
**Behavior:** assumptions remain hypotheses; user selects and edits an angle.

## 5. Draft studio
**Sections:** script, storyboard, shot list, on-screen text, visual direction, voice-over, caption, CTA, disclosure.  
**Behavior:** edit each section independently; regenerating one section must not overwrite approved sections silently.

## 6. Review and approval
**Checks:** factual accuracy, product match, rights, AI disclosure, affiliate disclosure, offer/link, platform rules, final render.  
**Actions:** Request changes / Approve.  
**Behavior:** critical unresolved checks block approval; human action is required.

## 7. Publishing log
**Fields:** platform, post URL, date/time, format, asset version, disclosure status.  
**Behavior:** Published requires operator confirmation and a real reference.

## 8. Results and experiments
**Fields:** metric, value, unit, source, reporting period, recorded date, notes.  
**Behavior:** missing metrics remain blank; estimated values are visibly distinguished.

## 9. Templates
Show reusable briefs, prompts, review checklists, export formats, version, and last update.

## 10. Settings
Show preferences and integration status. Never expose secret values; display masked status and safe actions only.
