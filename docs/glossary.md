# KURALIVO — Glossary

- **AI Content Engine:** workflow for researching, planning, drafting, reviewing, exporting, and learning from content.
- **Asset:** one output such as hook, script, storyboard, caption, voice-over, or visual.
- **Evidence pack:** sourced facts, limitations, dates, and rights notes used to ground content.
- **Creative angle:** framing of a specific audience problem or buyer question.
- **Human review gate:** explicit operator review before approval.
- **Affiliate account:** separate public account for eligible affiliate publishing; name TBD.
- **Affiliate eligibility:** current account/program permission to use a specific affiliate feature or link.
- **Observed metric:** value reported by a named source for a stated period.
- **Hypothesis:** a testable explanation not yet established by observations.
- **Approved asset:** specific version that passed required checks and received human approval.
- **Planned:** intended capability not confirmed as implemented.
- **Not connected:** external integration without a verified active connection.
